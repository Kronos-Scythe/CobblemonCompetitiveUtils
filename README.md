# Cobblemon Competitive Utils

A Fabric mod for [Cobblemon](https://cobblemon.com) 1.8.1 (Minecraft 1.21.1)
for competitive play. It gives Pokémon
[PokeRogue](https://pokerogue.net)'s abilities and egg moves, and adds an
in-game EV editor that can charge [CobbleDollars](https://www.curseforge.com/minecraft/mc-mods/cobbledollars).

> **Status: in development.** See [`PLAN.md`](PLAN.md) for the roadmap and
> design notes.

## Features

### PokeRogue abilities and egg moves

The mod ships Cobblemon *species additions* (a datapack inside the jar) for
all 1025 base species:

- **Abilities** follow PokeRogue's regular and hidden abilities. PokeRogue's
  passive ability is added as an extra regular ability. For example, Smeargle
  can roll Own Tempo, Technician or Prankster.
- **Egg moves** are replaced with PokeRogue's egg moves.
- **Filtered:** anything PokeRogue hasn't implemented, and any ability or move
  no Cobblemon species has, is left out.

Cobblemon's jar is never modified. These files are generated by the Python
tools in [`tools/`](#regenerating-the-species-data).

Not covered yet: regional forms and other alternate forms, and true passives
(a second ability active at the same time).

### `/evedit`: EV editor

`/evedit` opens a chest menu with your party, shown as the Pokémon models (a
Poké Ball marks an empty slot). Click a Pokémon to edit its EVs. Each stat is
shown by its power item:

| Stat | Item |
| --- | --- |
| HP | Power Weight |
| Attack | Power Bracer |
| Defense | Power Belt |
| Sp. Atk | Power Lens |
| Sp. Def | Power Band |
| Speed | Power Anklet |

Hover a stat to see its current EVs, the resulting stat value, how high it can
go, and the price.

| Input | Effect |
| --- | --- |
| Left / right click | +1 / −1 |
| Shift + left / right click | +4 / −4 |
| Ctrl + Q (drop stack) | Max: 252, or whatever the 510 total allows |
| Q (drop item) | Reset to 0 |

Nothing can be taken out of the menu. Editing is refused during a battle.

### CobbleDollars prices

With CobbleDollars installed, adding EVs costs CobbleDollars. Unaffordable
clicks are refused, and Ctrl + Q buys as many EVs as your balance allows.
Without CobbleDollars, editing is free.

Prices are in `config/cobblecomputils/evedit.json`, created on first start:

```json
{
  "charge": true,
  "pricePerEv": {
    "hp": 10, "attack": 10, "defence": 10,
    "special_attack": 10, "special_defence": 10, "speed": 10
  },
  "refundPercent": 0
}
```

| Key | Meaning |
| --- | --- |
| `charge` | `false` makes editing free even with CobbleDollars installed |
| `pricePerEv` | CobbleDollars per EV added, per stat |
| `refundPercent` | Share of the price paid back when EVs are lowered (0–100) |

After editing the file, run `/evedit reload` (operators only).

## Requirements

Install on the **server** (or in singleplayer). Clients need Cobblemon and
Mega Showdown, as usual, but not this mod.

| Mod | Version | |
| --- | --- | --- |
| Minecraft | 1.21.1 | required |
| [Fabric Loader](https://fabricmc.net/use/) | 0.19.5 or newer | required |
| [Fabric API](https://modrinth.com/mod/fabric-api) | for 1.21.1 | required |
| [Fabric Language Kotlin](https://modrinth.com/mod/fabric-language-kotlin) | for 1.21.1 | required (Cobblemon needs it) |
| [Cobblemon](https://modrinth.com/mod/cobblemon) | 1.8.1 or newer | required |
| [Mega Showdown](https://github.com/yajatkaul/CobblemonMegaShowdown) | for Cobblemon 1.8 | required, with its own dependencies (Architectury API, Accessories) |
| [CobbleDollars](https://www.curseforge.com/minecraft/mc-mods/cobbledollars) | for 1.21.1 | optional, for prices |

## Building

You need **JDK 25** and git. Loom, the Fabric build plugin, needs Java 25
to run Gradle; the mod itself is still compiled for Java 21, so it runs on
any normal 1.21.1 install. Gradle is not required: the included wrapper
(`gradlew`) downloads the right version.

```sh
git clone https://github.com/Kronos-Scythe/CobblemonCompetitiveUtils.git
cd CobblemonCompetitiveUtils
./gradlew build          # Windows: gradlew.bat build
```

The mod jar is `build/libs/cobblemoncompetitiveutils-<version>.jar` (ignore
the `-sources` jar). Put it in your `mods/` folder with the requirements
above.

The first build takes a while: it downloads Minecraft, the mappings and all
dependencies.

> **Build with Gradle, not IntelliJ's "Build Artifacts".** Fabric mods have
> to go through Gradle (Loom), which packages the resources and remaps the
> code for the real game. An IntelliJ artifact comes out as a ~1 KB jar with
> nothing in it. In IntelliJ, use the Gradle tool window: *Tasks → build →
> build*. The right jar is several hundred KB and contains `fabric.mod.json`
> and `data/cobblecomputils/species_additions/`.

Every push is also built on GitHub (*Actions → Build*). Each run's
**cobblemoncompetitiveutils** artifact is a ready-to-use jar.

### Running in development

```sh
./gradlew runClient      # starts Minecraft with the mod and its dependencies
./gradlew runServer      # same, as a dedicated server (in ./run)
```

In IntelliJ IDEA, open the folder as a Gradle project. After the import,
Loom adds **Minecraft Client** and **Minecraft Server** run configurations.

### Dependency versions

All versions are in [`gradle.properties`](gradle.properties). Check two of
them when updating:

- `mega_showdown_version`: a Mega Showdown version number from Modrinth.
- `cobbledollars_version`: a CobbleDollars **Modrinth version ID**
  (e.g. `cqsHXSXe`), from its Modrinth versions page.

CobbleDollars is only on the compile classpath: the built jar doesn't require
it.

## Regenerating the species data

The files in `src/main/resources/data/cobblecomputils/species_additions/`
are generated. To regenerate them, for example after a Cobblemon or PokeRogue
update, you need **Python 3.10+** and:

- `pokedex_data.js` and `en.js` from
  [PokeRogue-Dex](https://github.com/Sandstormer/PokeRogue-Dex) (the script
  can also download them)
- the Cobblemon Fabric jar and the Mega Showdown Fabric jar

```sh
python tools/pokerogue_extract.py --items pokedex_data.js --lang en.js
python tools/pokerogue_status.py
python tools/build_additions.py --cobblemon cobblemon-fabric-1.8.1.jar mega_showdown-fabric.jar --passive ability
```

The last step only *reads* the jars. It writes the additions to
`generated/data/cobblecomputils/species_additions/`, and lists everything it
dropped or skipped in `generated/report.txt`. Review the report, then copy
the JSON files into `src/main/resources/data/cobblecomputils/species_additions/`.

The builder's rules and options are documented in [`PLAN.md`](PLAN.md) and in
each script's `--help`.

