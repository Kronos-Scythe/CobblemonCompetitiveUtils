# Reference sources (v1.24)

The complete source of the released `cobblemoncompetitiveutils-1.24.jar`, as it was
built for the Potential Pack. It uses **intermediary** names (`class_1799`, `method_7964`, ...)
because it was compiled against the remapped game jars, not against Yarn.

It is kept here so the work is not lost. It is **not part of the Gradle build**.
Porting it to Yarn names (and moving it into `src/main/java` / `src/client/java`) is the next step.
